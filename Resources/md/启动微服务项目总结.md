## 一、项目概况

**天机学堂（tjxt）** 是基于 Spring Cloud Alibaba 的在线教育平台，共 **15 个微服务模块**。

| 技术 | 版本 |
|---|---|
| Spring Boot | 3.3.5 |
| Spring Cloud | 2023.0.3 |
| Spring Cloud Alibaba | 2023.0.3.2 |
| JDK | 17 |
| MyBatis-Plus | 3.5.9 |

## 四、Nacos 配置中心

### 4.1 共享配置（6 个，DEFAULT_GROUP）

| DataId | 内容要点 |
|--------|---------|
| shared-spring.yaml | ⚠️ **不含数据源**（数据源由各服务独立配置，避免覆盖问题） |
| shared-redis.yaml | `spring.data.redis.host: 127.0.0.1, port: 6379` |
| shared-mybatis.yaml | 驼峰映射 + SQL 日志 |
| shared-logs.yaml | `logging.level.com.tianji: debug` |
| shared-feign.yaml | 超时 5s |
| shared-mq.yaml | 项目实际用 Spring AMQP（RabbitMQ），默认连 localhost:5672 |

### 4.2 各服务独立配置（`{服务名}.yaml`）

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/tj_{库名}?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: root
    password: 412826
    driver-class-name: com.mysql.cj.jdbc.Driver
seata:
  enabled: false
```

### 4.3 发布配置（PowerShell）

```powershell
$yaml = "spring:`n  datasource:`n    url: jdbc:mysql://127.0.0.1:3306/tj_auth?...`n    username: root`n    password: 412826`n    driver-class-name: com.mysql.cj.jdbc.Driver`nseata:`n  enabled: false"
$body = "dataId=auth-service.yaml&group=DEFAULT_GROUP&type=yaml&content=" + [System.Uri]::EscapeDataString($yaml)
Invoke-RestMethod -Uri "http://127.0.0.1:8848/nacos/v1/cs/configs" -Method Post -Body $body -ContentType "application/x-www-form-urlencoded"
```

> **必须使用 `Invoke-RestMethod` + `EscapeDataString`**，用 curl -d 会丢失换行符。
> 纯注释内容会被 Nacos 视为空配置，需发布有效 YAML（如 `spring: {}`）。

## 七、搜索与 ES 索引同步

1. search-service 通过 **RabbitMQ**（交换机 `course.topic`）消费课程上/下架消息，同步到 ES `course` 索引
2. 存量数据手动触发同步：

```powershell
# 获取已上架课程 id 后调用 search 的补偿接口
curl -X POST "http://127.0.0.1:10010/ss/courses/up?courseIds=1,2,3,..."
# 验证
curl "http://127.0.0.1:9200/course/_count"   # 期望 count=12
```

3. 搜索接口验证：`/ss/courses/portal`、`/ss/courses/name?keyword=Java`

## 九、启动踩坑记录

### 9.1 数据源被共享配置覆盖（已解决）

- **现象**：user-service 查询报 `Table 'tj_auth.user' doesn't exist`
- **原因**：`shared-spring.yaml`（指向 tj_auth）在 import 顺序中排在服务配置之后，后导入的覆盖先导入的，所有服务数据源被强制为 tj_auth
- **解决**：清空 `shared-spring.yaml` 中的数据源，数据源由各服务独立配置

### 9.2 网关 user-info 透传 bug（已修复代码）

- **现象**：登录成功但所有需要登录的接口返回 401
- **原因**：[AccountAuthFilter.java](file:///d:/daima/待学习/tianjixuetang/tjxt/tj-gateway/src/main/java/com/tianji/gateway/filter/AccountAuthFilter.java) 中 `exchange.mutate().build()` 结果未赋值回 `exchange`，`user-info` 头从未真正转发
- **解决**：修复后重新编译 `mvn package -pl tj-gateway -am -DskipTests`

### 9.3 内存不足服务被杀（已解决）

- **现象**：同时启动 13 个服务后，部分进程被系统挤掉
- **原因**：15.8GB 内存被 ES×2 + Nacos + SonarQube 占满
- **解决**：停止 SonarQube + 所有服务限制 `-Xmx512m`

### 9.4 ES 无 course 索引（已解决）

- **现象**：搜索接口 500 `no such index [course]`
- **解决**：RabbitMQ 启动后，调用 `/ss/courses/up` 补偿接口同步存量课程

### 9.5 其他

- 登录接口 500 先查 JSON 传参：PowerShell 中 curl 传 JSON 需用 `--data-binary @file`，避免引号丢失
- gateway 启动时"加载 auth 服务地址失败"为正常重试（10s 周期），auth 起来后自动成功
