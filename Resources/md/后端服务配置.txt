### 9.1 基础设施依赖

| 组件                   | 统一配套版本                          |
| -------------------- | ------------------------------- |
| Spring Cloud Alibaba | 2023.0.1.0                      |
| Nacos Client         | 2.3.0                           |
| Apache Dubbo         | 3.2.14                          |
| Sentinel             | 1.8.6                           |
| Seata                | 2.0.0                           |
| RocketMQ Client      | 5.1.4                           |
| OpenFeign            | 4.1.0（Spring Cloud 2023.0.3 自带） |

在启动项目之前，需要先准备好以下基础设施服务：

| 基础设施          | 版本/地址                 | 用途          | 必填        |
| ------------- | --------------------- | ----------- | --------- |
| Nacos         | 192.168.150.101:8848  | 注册中心 + 配置中心 | ✅ 必填      |
| MySQL         | 8.0.23                | 关系型数据库      | ✅ 必填      |
| Redis         | 192.168.150.101:16379 | 缓存          | ✅ 必填      |
| MongoDB       | 192.168.150.101:27017 | NoSQL数据库    | ⚠️ AIGC需要 |
| Elasticsearch | 7.12.1                | 全文搜索        | ⚠️ 搜索服务需要 |
| RocketMQ      | -                     | 消息队列        | ⚠️ 部分服务需要 |
| Seata         | 1.5.1                 | 分布式事务       | ⚠️ 交易相关需要 |
| XXL-Job       | 2.3.1                 | 定时任务调度      | ⚠️ 部分服务需要 |

> **注意**：Nacos配置中心包含各服务的数据库连接、Redis连接等共享配置，必须确保Nacos正常运行且配置完整。
