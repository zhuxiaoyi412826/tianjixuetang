# 天机学堂后端项目启动流程

## 一、启动前准备

### 1.1 环境要求

| 环境 | 版本要求 | 检查命令 |
|------|---------|---------|
| JDK | 17.x | `java -version` |
| Maven | 3.6+ | `mvn -version` |
| 操作系统 | Windows / Linux | - |

### 1.2 基础设施依赖

| 基础设施 | 端口 | 用途 | 最小化 | 完全化 |
|---------|------|------|--------|--------|
| Nacos | 8848 | 注册中心 + 配置中心 | ✅ | ✅ |
| MySQL | 3306 | 关系型数据库 | ✅ | ✅ |
| Redis | 6379 | 缓存 | ✅ | ✅ |
| Elasticsearch | 9200 | 全文搜索 | ❌ | ✅ |
| MongoDB | 27017 | NoSQL数据库 | ❌ | ✅ |
| RocketMQ | 9876 | 消息队列 | ❌ | ⚠️ 可选 |
| Seata | 8091 | 分布式事务 | ❌ | ⚠️ 可选 |
| XXL-Job | 8800 | 定时任务调度 | ❌ | ⚠️ 可选 |

> **✅ 必须启动** | **❌ 不需要** | **⚠️ 可选**

### 1.3 基础设施启动命令

#### Windows环境

```batch
:: Nacos 启动
cd nacos-server-2.3.0\bin
startup.cmd -m standalone

:: Redis 启动（如果使用本地Redis）
redis-server.exe

:: Elasticsearch 启动
cd elasticsearch-7.12.1\bin
elasticsearch.bat
```

#### Docker方式（推荐）

```bash
# Nacos
docker run -d --name nacos230 -p 8848:8848 -e MODE=standalone nacos/nacos-server:v2.3.0

# Redis
docker run -d --name redis -p 6379:6379 redis:7

# Elasticsearch
docker run -d --name es7 -p 9200:9200 -e "discovery.type=single-node" elasticsearch:7.12.1

# MongoDB
docker run -d --name mongo -p 27017:27017 mongo:6
```

## 二、模式一：最小化启动

### 2.1 适用场景

- 开发调试
- 核心功能验证
- 资源有限时快速启动

### 2.2 启动的服务

| 序号 | 服务模块 | 服务名 | 功能说明 |
|------|---------|--------|---------|
| 1 | tj-common | - | 公共模块（需先编译安装） |
| 2 | tj-api | - | API定义模块（需先编译安装） |
| 3 | tj-auth | auth-service | 用户认证与授权 |
| 4 | tj-user | user-service | 用户管理 |
| 5 | tj-course | course-service | 课程管理 |
| 6 | tj-learning | learning-service | 学习进度跟踪 |
| 7 | tj-gateway | gateway-service | API网关（最后启动） |

### 2.3 依赖的基础设施

- ✅ Nacos (8848)
- ✅ MySQL (3306)
- ✅ Redis (6379)

### 2.4 启动步骤

```
步骤1: 启动基础设施 (Nacos + MySQL + Redis)
  ↓
步骤2: 编译公共模块 (tj-common, tj-api)
  ↓
步骤3: 启动认证服务 (tj-auth)
  ↓
步骤4: 启动用户服务 (tj-user)
  ↓
步骤5: 启动课程服务 (tj-course)
  ↓
步骤6: 启动学习服务 (tj-learning)
  ↓
步骤7: 启动网关服务 (tj-gateway)
```

### 2.5 详细命令

```bash
# ========== 步骤2：编译公共模块 ==========
cd d:\daima\XiangMu\tianjixuetang\tjxt

# 安装公共模块到本地仓库
mvn install -pl tj-common,tj-api -am -DskipTests

# 编译所有服务（跳过测试）
mvn clean package -DskipTests


# ========== 步骤3：启动认证服务 ==========
cd tj-auth/tj-auth-service
start "auth-service" cmd /k "java -jar target/tj-auth-service.jar --spring.profiles.active=local"

# 等待 5 秒
timeout /t 5 /nobreak


# ========== 步骤4：启动用户服务 ==========
cd ..\..\tj-user
start "user-service" cmd /k "java -jar target/tj-user.jar --spring.profiles.active=local"

# 等待 3 秒
timeout /t 3 /nobreak


# ========== 步骤5：启动课程服务 ==========
cd ..\tj-course
start "course-service" cmd /k "java -jar target/tj-course.jar --spring.profiles.active=local"

# 等待 3 秒
timeout /t 3 /nobreak


# ========== 步骤6：启动学习服务 ==========
cd ..\tj-learning
start "learning-service" cmd /k "java -jar target/tj-learning.jar --spring.profiles.active=local"

# 等待 3 秒
timeout /t 3 /nobreak


# ========== 步骤7：启动网关服务 ==========
cd ..\tj-gateway
start "gateway-service" cmd /k "java -jar target/tj-gateway.jar --spring.profiles.active=local"
```

## 五、常见问题排查

### 5.1 服务注册失败

**现象**：Nacos 控制台看不到服务

**排查步骤**：
1. 检查 Nacos 是否正常运行
2. 检查 `application-local.yml` 中 `server-addr` 配置是否正确
3. 检查防火墙是否阻止端口通信

### 5.2 数据库连接失败

**现象**：服务启动报 `Communications link failure`

**排查步骤**：
1. 确认 MySQL 已启动
2. 确认 Nacos 中数据库连接配置正确
3. 确认数据库已创建

### 5.3 Redis 连接失败

**现象**：报 `RedisConnectionFailureException`

**排查步骤**：
1. 确认 Redis 已启动
2. 确认 Nacos 中 Redis 配置正确

### 5.4 端口冲突

**现象**：报 `Address already in use`

**解决**：
```bash
# Windows：查找占用端口的进程
netstat -ano | findstr :端口号

# 杀掉进程
taskkill /PID 进程号 /F
```

### 5.5 编译失败

**现象**：Maven 编译报错

**排查步骤**：
1. 确认 JDK 17 已安装
2. 执行 `mvn clean` 后重试
3. 检查 Maven 仓库是否有损坏的依赖

### 5.6 媒体服务启动失败

**现象**：媒体服务启动报腾讯云/阿里云相关错误

**说明**：媒体服务依赖云服务配置，如无需此功能可跳过启动

### 5.7 搜索服务启动失败

**现象**：搜索服务启动报 Elasticsearch 连接错误

## 七、停止服务

### Windows方式

1. **通过窗口关闭**：直接关闭对应的 CMD 窗口
2. **通过命令杀掉**：

```batch
# 查找所有Java进程
tasklist | findstr java

# 杀掉指定进程
taskkill /PID 进程号 /F
```

### 一键停止所有

创建文件 `stop-all.bat`：

```batch
@echo off
chcp 65001
echo ========================================
echo 天机学堂 - 停止所有服务
echo ========================================

echo 正在停止所有Java服务...
for /f "tokens=2" %%a in ('tasklist ^| findstr java') do (
    taskkill /PID %%a /F
)

echo.
echo 所有服务已停止！
pause
```
