### 2.3 通过 Nacos API 发布配置

```powershell
# 示例：发布 auth-service.yaml
$yaml = @"
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/tj_auth?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
    username: root
    password: 412826
    driver-class-name: com.mysql.cj.jdbc.Driver
seata:
  enabled: false
"@
$body = "dataId=auth-service.yaml&group=DEFAULT_GROUP&type=yaml&content=" + [System.Uri]::EscapeDataString($yaml)
Invoke-RestMethod -Uri "http://127.0.0.1:8848/nacos/v1/cs/configs" -Method Post -Body $body -ContentType "application/x-www-form-urlencoded"
```

> **注意**：发布配置时必须使用 `Invoke-RestMethod` 并通过 `[System.Uri]::EscapeDataString()` 编码内容，不能直接使用 `curl.exe -d` 传递，否则 YAML 换行符会丢失导致格式损坏。

## 六、启动过程中遇到的问题及解决方案

### 问题1：MySQL 密码不匹配

**现象**：Nacos 配置中密码为 `root`，但实际 MySQL 密码为 `412826`

**解决**：通过 Nacos API 更新所有服务配置中的密码

```powershell
$databases = @{
    "auth-service" = "tj_auth"
    "user-service" = "tj_user"
    # ... 其他服务
}
foreach ($svc in $databases.Keys) {
    $db = $databases[$svc]
    $yaml = "spring:`n  datasource:`n    url: jdbc:mysql://127.0.0.1:3306/$db`?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai`n    username: root`n    password: 412826`n    driver-class-name: com.mysql.cj.jdbc.Driver`nseata:`n  enabled: false"
    $body = "dataId=$svc.yaml&group=DEFAULT_GROUP&type=yaml&content=" + [System.Uri]::EscapeDataString($yaml)
    Invoke-RestMethod -Uri "http://127.0.0.1:8848/nacos/v1/cs/configs" -Method Post -Body $body -ContentType "application/x-www-form-urlencoded"
}
```

### 问题2：Nacos 配置 YAML 格式损坏

**现象**：使用 `curl.exe -d` 发布配置时，YAML 换行符丢失，内容变成一行

**解决**：改用 `Invoke-RestMethod` + `[System.Uri]::EscapeDataString()` 发布，保留换行符

### 问题3：搜索服务缺少 Elasticsearch 配置

**现象**：搜索服务的 `application-local.yml` 中没有 ES 连接配置

**解决**：两种方式
1. 启动时通过命令行参数传递：`--spring.elasticsearch.uris=http://127.0.0.1:9200`
2. 修改 `application-local.yml` 添加 ES 配置（需重新编译 jar）

### 问题4：数据库不存在

**现象**：服务启动后无法连接数据库

**解决**：创建所有 14 个 tj_ 前缀数据库

### 问题5：Seata 未启动导致服务启动失败

**解决**：在所有 Nacos 服务配置中添加 `seata.enabled: false` 禁用分布式事务

### 问题6：网关 NPE 错误

**解决**：在 Nacos `gateway-service.yaml` 中配置 `tj.auth.exclude-path` 白名单

## 八、一键启动脚本

### 8.1 完整启动脚本（Windows PowerShell）

```powershell
# start-all.ps1
$PROJECT_DIR = "d:\daima\XiangMu\tianjixuetang\tjxt"

# 1. 启动认证服务
Write-Host "[1/13] 启动 auth-service..."
Start-Process -FilePath "java" -ArgumentList "-jar", "target/tj-auth-service.jar", "--spring.profiles.active=local" -WorkingDirectory "$PROJECT_DIR\tj-auth\tj-auth-service" -WindowStyle Normal
Start-Sleep -Seconds 15

# 2. 启动核心服务
$coreServices = @(
    @{Name="user-service"; Path="$PROJECT_DIR\tj-user"; Jar="tj-user.jar"},
    @{Name="course-service"; Path="$PROJECT_DIR\tj-course"; Jar="tj-course.jar"},
    @{Name="learning-service"; Path="$PROJECT_DIR\tj-learning"; Jar="tj-learning.jar"}
)
foreach ($svc in $coreServices) {
    Write-Host "启动 $($svc.Name)..."
    Start-Process -FilePath "java" -ArgumentList "-jar", "target/$($svc.Jar)", "--spring.profiles.active=local" -WorkingDirectory $svc.Path -WindowStyle Normal
    Start-Sleep -Seconds 5
}

# 3. 启动搜索服务（含ES配置）
Write-Host "启动 search-service..."
Start-Process -FilePath "java" -ArgumentList "-jar", "target/tj-search.jar", "--spring.profiles.active=local", "--spring.elasticsearch.uris=http://127.0.0.1:9200" -WorkingDirectory "$PROJECT_DIR\tj-search" -WindowStyle Normal
Start-Sleep -Seconds 5

# 4. 启动其他业务服务
$otherServices = @(
    @{Name="trade-service"; Path="$PROJECT_DIR\tj-trade"; Jar="tj-trade.jar"},
    @{Name="promotion-service"; Path="$PROJECT_DIR\tj-promotion"; Jar="tj-promotion.jar"},
    @{Name="remark-service"; Path="$PROJECT_DIR\tj-remark"; Jar="tj-remark.jar"},
    @{Name="exam-service"; Path="$PROJECT_DIR\tj-exam"; Jar="tj-exam.jar"},
    @{Name="data-service"; Path="$PROJECT_DIR\tj-data"; Jar="tj-data.jar"},
    @{Name="message-service"; Path="$PROJECT_DIR\tj-message\tj-message-service"; Jar="tj-message-service.jar"},
    @{Name="pay-service"; Path="$PROJECT_DIR\tj-pay\tj-pay-service"; Jar="tj-pay-service.jar"}
)
foreach ($svc in $otherServices) {
    Write-Host "启动 $($svc.Name)..."
    Start-Process -FilePath "java" -ArgumentList "-jar", "target/$($svc.Jar)", "--spring.profiles.active=local" -WorkingDirectory $svc.Path -WindowStyle Normal
    Start-Sleep -Seconds 3
}

# 5. 启动网关
Write-Host "[13/13] 启动 gateway-service..."
Start-Process -FilePath "java" -ArgumentList "-jar", "target/tj-gateway.jar", "--spring.profiles.active=local" -WorkingDirectory "$PROJECT_DIR\tj-gateway" -WindowStyle Normal
Start-Sleep -Seconds 10

# 6. 验证
Write-Host "`n=== 验证服务注册状态 ==="
$result = curl.exe -s "http://127.0.0.1:8848/nacos/v1/ns/catalog/services?pageNo=1&pageSize=30&namespaceId=public"
Write-Host $result
```
