# 天机学堂项目识别报告

## 一、项目概述

**天机学堂 (Tianji Learning)** 是一个基于微服务架构的在线教育平台，由学成在线项目升级而来。项目包含**用户端**和**管理后台**两个部分，实现了完整的在线教育业务流程。

### 项目架构图

```
┌─────────────────────────────────────────────────────────────┐
│                      天机学堂项目                            │
├─────────────────────────────────────────────────────────────┤
│  前端层: Vue3 + Vite + Element Plus                         │
│  网关层: Spring Cloud Gateway (端口: 10010)                  │
│  微服务层: 17个后端服务                                      │
│  数据层: MySQL + Redis + Elasticsearch + MongoDB            │
│  云服务: 阿里云OSS/支付 + 腾讯云COS/VOD                       │
└─────────────────────────────────────────────────────────────┘
```

#### 9.2.2 启动顺序（重要）

后端微服务必须按照以下顺序启动，否则会出现服务找不到的错误：

```
第一步：基础设施启动
    ↓
第二步：公共模块编译安装 (tj-common, tj-api)
    ↓
第三步：认证服务 (tj-auth)
    ↓
第四步：核心业务服务 (tj-user, tj-course, tj-media)
    ↓
第五步：其他业务服务 (learning, trade, pay, exam, promotion, remark, search, data, message)
    ↓
第六步：AI服务 (tj-aigc) 【可选】
    ↓
第七步：网关服务 (tj-gateway)
    ↓
第八步：前端项目
```

#### 9.2.3 详细启动步骤

**步骤1：确保基础设施已启动**

确保以下服务已正常运行：
- Nacos (端口: 8848)
- MySQL (端口: 3306)
- Redis (端口: 6379 / 16379)

**步骤2：编译公共模块**

```bash
# 进入后端项目目录（以tjxt为例）
cd tjxt

# 先安装公共模块到本地仓库
mvn install -pl tj-common,tj-api -am -DskipTests
```

**步骤3：编译所有模块**

```bash
# 编译整个项目（跳过测试）
mvn clean package -DskipTests
```

**步骤4：启动认证服务**

```bash
# 启动认证服务
cd tj-auth/tj-auth-service
java -jar target/tj-auth-service.jar --spring.profiles.active=local
```

> 认证服务是其他服务的依赖，必须最先启动业务服务

**步骤5：启动核心业务服务**

```bash
# 启动用户服务
cd tj-user
java -jar target/tj-user.jar --spring.profiles.active=local

# 启动课程服务
cd tj-course
java -jar target/tj-course.jar --spring.profiles.active=local

# 启动媒体服务
cd tj-media
java -jar target/tj-media.jar --spring.profiles.active=local
```

**步骤6：启动其他业务服务**

```bash
# 学习服务
java -jar tj-learning/target/tj-learning.jar --spring.profiles.active=local

# 交易服务
java -jar tj-trade/target/tj-trade.jar --spring.profiles.active=local

java -jar tj-pay/tj-pay-service/target/tj-pay-service.jar --spring.profiles.active=local

# 考试服务
java -jar tj-exam/target/tj-exam.jar --spring.profiles.active=local

# 促销服务
java -jar tj-promotion/target/tj-promotion.jar --spring.profiles.active=local

# 评论服务
java -jar tj-remark/target/tj-remark.jar --spring.profiles.active=local

# 搜索服务（需要Elasticsearch）
java -jar tj-search/target/tj-search.jar --spring.profiles.active=local

# 数据服务
java -jar tj-data/target/tj-data.jar --spring.profiles.active=local

# 消息服务
java -jar tj-message/tj-message-service/target/tj-message-service.jar --spring.profiles.active=local
```

**步骤7：启动AI服务（可选）**


**步骤8：启动网关服务**

```bash

```

> 网关服务端口: `10010`，所有请求通过网关转发

**步骤2：配置代理**

前端通过Vite代理访问后端接口，代理配置在 `vite.config.js` 中：

```javascript
// vite.config.js
server: {
  port: 18082,
  host: '0.0.0.0',
  proxy: {
    '/api': {
      target: 'http://api.tianji.com',  // 后端网关地址
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

#### 9.4.3 多服务启动方式

在Windows环境下，建议使用以下方式启动多个服务：

**方式一：使用多个CMD/PowerShell窗口**

每个服务在单独的窗口中启动，方便查看日志。

**方式二：使用IDEA启动（推荐开发时使用）**

1. 用IDEA打开后端项目
2. 找到各服务的启动类（`*Application.java`）
3. 按顺序点击运行

**方式三：编写启动脚本**

创建 `start-all.bat` 批处理脚本：

```batch
@echo off
echo ========================================
echo 天机学堂后端服务启动脚本
echo ========================================

echo [1/15] 启动认证服务...
start "auth-service" cmd /k "cd tj-auth\tj-auth-service && java -jar target\tj-auth-service.jar --spring.profiles.active=local"

timeout /t 5 /nobreak

echo [2/15] 启动用户服务...
start "user-service" cmd /k "cd tj-user && java -jar target\tj-user.jar --spring.profiles.active=local"

timeout /t 3 /nobreak

echo [3/15] 启动课程服务...
start "course-service" cmd /k "cd tj-course && java -jar target\tj-course.jar --spring.profiles.active=local"

rem ... 其他服务

echo 所有服务已启动，请查看各窗口日志
pause
```
